## 0. 冻结决策（以本页为准）

1. **实现 baseline（代码底座）**：**AEGIS**（arXiv:2511.17747，全文与开源可及）——优化 3D 人脸高斯的颜色系数，经可微渲染、由人脸验证网络引导。  
2. **本章相对 AEGIS 的三条硬差分**：  
   - 目标：去身份 / 躲避 → **定向冒充**目标身份 \(y_{\mathrm{tgt}}\)；  
   - 作用域：全脸/全局颜色扰动 → **唇、眼、眉、颊语义妆容 mask 内残差**；  
   - 迁移：原代理设定 → **DPA 式多样参数代理** + **检测—裁剪—对齐—压缩预处理不变**（专打商业 API）。  
3. **中期最优**（RGB 残差 + API-EoT + 身份方向）：降为**强消融 / 内部对照**，不再作为对外主 baseline。  
4. **3DAO**（KBS’26，3DGS 眼镜/面具打人脸）：任务最贴「攻击」，全文待校园网；有全文后作文案与协议对照，**不改成配饰物课题**。  
5. **DiffAM / Adv-Makeup**：妆容黑盒协议与数字对照；**不复现 2D 扩散系统**。  
6. **何利军 SADU**：可选域自通用损失，**默认消融**；只借问题结构，实验域禁止写成 ImageNet 复现。

## 1. 为什么换底座：中期自研不够强时的选择逻辑

### 1.1 中期自研的价值与局限
**价值**：已验证 3DGS 局部妆容残差可行，有 `mean_delta` 定义与多目标黑盒试跑。  
**局限**：对外叙事上「自己当唯一 baseline」偏弱，审稿/答辩易被问：相对已发表 3DGS 工作改进了什么？

### 1.2 候选公开 3DGS 工作怎么排

| 工作 | 与课题贴合度 | 能否当实现底座 | 结论 |
|---|---|---|---|
| **AEGIS** | 3D 人脸高斯 + 改颜色系数 + FR 网络 + 多视角 | 有全文/开源，接口最近 | **选作实现 baseline** |
| **3DAO** | 3DGS + 打人脸识别 + 多视角 | 全文墙后；且是眼镜/面具 | 任务对照，不改妆容叙事 |
| **GSAttack** | 3DGS 多视角对抗 | 墙后；主任务偏分类 | 相关工作 |
| **PGA** | 3DGS 物理伪装 | 非人脸识别主线 | 不当底座 |
| **AT3D** | 物理人脸、商业 API | Mesh 纹理，非 3DGS | 协议/物理对照 |

**选择 AEGIS 的理由（非凭空）**：  
公开文献里几乎没有「3DGS + 皮肤语义妆容 + 定向冒充 API」的现成 SOTA；在可复现约束下，AEGIS 提供了**合法、可核验的 3DGS 颜色优化接口**，本章用三条差分把它改成妆容定向冒充 + 黑盒迁移增强——改进点干净、可消融。

## 3. 方法总览：AEGIS 底座 + 三差分 + 两嫁接（+ 一可选）

### 3.1 一句话主张
以 **AEGIS** 的「仅优化高斯颜色系数、保持几何与多视角一致」为实现底座，改为 **语义区妆容残差上的定向冒充**，并用 **DPA 多样代理** 与 **预处理/渲染不变期望** 提升对商业人脸 API 的定向迁移；`mean_delta`（或 ASR）与自然性指标并列报告。

### 3.2 形式化（审定稿）

- 三维头像高斯集 \(G\)；优化量 \(\delta\) 为 **mask \(M\)（唇/眼/眉/颊）内** 的颜色（DC/RGB）残差，幅度受 \(\varepsilon\) 约束。  
- 渲染 \(R(G+\delta, v)\)，\(v\sim\mathcal{V}\)（视角/光照）。  
- \(t\)：轻量几何/色彩变换；\(A\)：检测—裁剪—对齐—压缩等预处理；\(f\in\mathcal{F}_{\mathrm{DPA}}\)。

\[
\min_{\delta:\ \mathrm{supp}(\delta)\subseteq M,\ \|\delta\|_\infty\le\varepsilon}
\mathbb{E}_{v,t,A,f}
\Big[
\mathcal{L}_{\mathrm{id}}\big(A(t(R(G+\delta,v))),\, y_{\mathrm{tgt}};\, f\big)
\Big]
+\lambda_{\mathrm{nat}}\mathcal{L}_{\mathrm{nat}}(\delta)
+\lambda_{\mathrm{univ}}\mathcal{L}_{\mathrm{univ}}(\delta)
\]

- 默认 \(\lambda_{\mathrm{univ}}=0\)（SADU 式域自通用仅消融）。  
- **DiffAM 不进入此式**，只进评测协议。

## 4. 分模块说明（问题 → 文献 → 动作 → 不做）

### 4.1 模块 B：复用 AEGIS 优化接口（底座）

| 项 | 内容 |
|---|---|
| **解决** | P1：需要可发表、可复现的 3DGS 人脸颜色优化起点 |
| **依据** | AEGIS：扰动球谐/颜色系数，不改几何，多视角一致，FR 网络引导 |
| **动作** | 复用其可微渲染与颜色参数化；保留「不改几何」以维持头像可用性与多视角一致性 |
| **不做** | 不复现其「隐私去身份」结论叙事；不把 AEGIS 的躲避损失原样当最终损失 |

### 4.2 模块 D1：定向冒充损失（相对 AEGIS 差分①）

| 项 | 内容 |
|---|---|
| **解决** | P2：去身份 ≠ 冒充；安全评测需要定向威胁模型 |
| **依据** | 人脸对抗中定向/冒充设定（中期已用相似度提升；何利军强调定向更难迁移）；商业 API 比对分数可定义 `delta` |
| **动作** | \(\mathcal{L}_{\mathrm{id}}\) 推动渲染特征接近目标身份 \(y_{\mathrm{tgt}}\)（延续中期身份方向思想，接到 AEGIS 管线） |
| **不做** | 不把主任务写成「验证失败即可」的纯躲避 |

### 4.3 模块 D2：语义妆容 mask（相对 AEGIS 差分②）

| 项 | 内容 |
|---|---|
| **解决** | P3：全局颜色扰动观感差、难物理解释为妆容 |
| **依据** | Adv-Makeup（IJCAI’21）、DiffAM（CVPR’24）证明妆容是合理隐蔽载体；中期已建唇眼眉颊 mask |
| **动作** | \(\mathrm{supp}(\delta)\subseteq M\)，加调色板/平滑/LPIPS 等 \(\mathcal{L}_{\mathrm{nat}}\) |
| **不做** | 不改为 3DAO 眼镜/面具；不重做 DiffAM 扩散妆容生成器 |

### 4.4 模块 T1：DPA 多样代理（嫁接）

| 项 | 内容 |
|---|---|
| **解决** | P0/P4：黑盒泛化弱、代理同质 |
| **依据** | DPA（CVPR’25）：多样参数优化 + 困难模型聚合提升 FR 攻击迁移 |
| **动作** | 构造 \(\mathcal{F}_{\mathrm{DPA}}\)，对 \(f\) 取期望/困难聚合；**优化对象仍是 \(\delta\)** |
| **不做** | 不把 DPA 的全图像素设定原样搬来替代妆容残差 |

### 4.5 模块 T2：预处理—渲染不变（嫁接）

| 项 | 内容 |
|---|---|
| **解决** | P5：API 检测/对齐导致迁移崩 |
| **依据** | PreprocessRobust（arXiv:2510.17169）：换检测器 ASR 可大跌；输入变换可挽回迁移 |
| **动作** | 期望中显式纳入 \(A\)（检测—裁剪—对齐—压缩）与 \(t\)；升级中期 API-EoT |
| **不做** | 不堆无文献支撑的「变换动物园」 |

### 4.6 模块 O：可选 \(\mathcal{L}_{\mathrm{univ}}\)（何利军 SADU 思想）

| 项 | 内容 |
|---|---|
| **解决** | 扰动在狭窄外观域内有效、跨风格不稳（次级） |
| **依据** | 何利军 SADU：源域与风格域特征对齐抬定向迁移 |
| **动作** | 默认关闭；消融时打开，看是否额外抬黑盒、是否伤自然性 |
| **不做** | 不写成 ImageNet/SU 攻击复现；不与 T2 概念重复堆砌 |

## 6. 实验交付协议

### 6.1 指标
- **攻击**：`mean_delta = mean(adv_score - clean_score)`（继承中期）；必要时补定向 ASR。  
- **自然性**：LPIPS、调色板/色偏、饱和度变化等，**与攻击指标同表并列**。  
- **多视角**：固定视角集合上报告均值/方差，体现 3D 一致性。

### 6.2 必跑设置
1. **AEGIS 原设定复现 sanity check**（去身份指标，证明底座接对）。正式主体冻结为 **NeRSemble 306**：已合并的 B0-a（`status=pipeline_ok`，`return_code=0`，`subject=306`）即正式 B0。**B0-b（FaceScape 527）已取消**，不在关键路径上，不再等待该主体；  
2. **AEGIS→定向冒充（全脸颜色，无 mask）**。冒充目标 T 是 CelebA 或 LFW 的一张静止人脸照片，经 AdaFace 得到嵌入，不是第二套 3DGS。盘上 NeRSemble 只有主体 306。第一刀样本是 `/root/autodl-fs/gs-assets/targets/celeba_T0.jpg`（盘上冻结名；仓库不收录整库）。后一刀是 `/root/autodl-fs/gs-assets/targets/lfw_T0.jpg`。上游 `AEGIS.run` 把裸 `tensor([1])` 交给 Foolbox，未定向 `Misclassification` 会降低与参考嵌入 `e_r` 的余弦；`--target-image` 只提供 `e_r`。B1 把 `e_r` 设成 T，准则改为匹配类（logit 下标 1）的 `TargetedMisclassification`，最大化 `cos(adv, emb(T))`。不装妆容钩子。照片就位前不启动 GPU。命令见仓库 README「B1」一节；  
3. **+ 语义妆容 mask + \(\mathcal{L}_{\mathrm{nat}}\)**；  
4. **+ \(\mathcal{F}_{\mathrm{DPA}}\)**；  
5. **+ 预处理族 \(A\)**；  
6. **完整方法**；  
7. **中期最优管线**（对照）；  
8. **DiffAM / Adv-Makeup 协议对照**（实现差异写清）；  
9. 可选：\(+\mathcal{L}_{\mathrm{univ}}\)；  
10. 有全文后：3DAO **文案对照**（不强制同表硬比 ASR）。

### 6.3 数据与黑盒
- 攻击者：3DGS / SplattingAvatar 头像；目标：LFW 等公开身份（扩大数量以稳统计）。B1 的冒充目标 T 从 CelebA 或 LFW 取一张静止照片（第一刀 `celeba_T0.jpg`，后一刀 `lfw_T0.jpg`），放在 `/root/autodl-fs/gs-assets/targets/`，不把整库放进仓库。  
- 黑盒：Baidu 等商业 API；固定查询次数、复测与费率记录，回应中期「反馈波动」。

### 6.4 成功标准（章节立住的最低条）
- 相对「AEGIS 改装容定向但无 DPA/无 \(A\)」在黑盒 `mean_delta` 上有稳定增益；  
- 自然性不显著差于带 \(\mathcal{L}_{\mathrm{nat}}\) 的中期设置；  
- 消融能分开 D1/D2/T1/T2 的贡献，禁止只有一个总分。
